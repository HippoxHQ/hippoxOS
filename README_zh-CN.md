## 概述

HippoxOS 是一款面向桌面环境的 AI 原生操作系统。它并非传统意义上的应用程序集合，而是一个以自然语言为中枢交互方式的完整操作系统级平台，旨在让用户通过对话完成对计算机资源的全面控制与调度。

HippoxOS 搭载了自研的 **Hippox 内核**，这是一个专为自然语言交互设计的操作系统内核。与传统操作系统内核不同，Hippox 内核不直接调度硬件资源，而是调度语言模型的能力、驱动程序（Drivers）的执行、工作流（Workflows）的编排以及系统资源的访问控制。基于 Hippox 内核，HippoxOS 构建了完整的驱动程序体系，将用户的自然语言输入转换为系统可执行的操作指令，实现对计算机的全面控制。

在 HippoxOS 中，自然语言不再仅仅是聊天助手的输入形式，而是上升为与文件系统、创作工具、数据可视化、代码开发环境以及自动化任务进行交互的第一接口。用户通过对话描述意图，系统解析并驱动 Hippox 内核调度相应的系统资源与驱动程序执行操作，从而大幅降低专业软件的使用门槛，提升人机协作效率。

## 设计理念

HippoxOS 的设计围绕以下三个核心原则展开：

1. **对话即界面（Conversation as Interface）**：自然语言是用户与系统所有功能交互的主要通道。用户不需要学习不同软件的菜单、快捷键或工作流，而是通过描述目标来驱动系统完成工作。

2. **领域原生集成（Domain-Native Integration）**：系统将多种专业领域工具——视频编辑、3D 建模、地理信息、金融分析、软件开发——作为原生能力深度集成，而非简单调用外部应用。每个领域都具备理解并执行该领域专业指令的能力。

3. **智能任务编排（Intelligent Task Orchestration）**：系统具备任务管理和自动化调度能力。用户可以设定定时任务，让系统按照指定的时间或间隔自动执行自然语言指令，实现无人值守的自动化工作流。

## 核心子系统

### 1. 通用对话子系统

https://github.com/user-attachments/assets/6b7a0a7f-d573-4e5b-a49a-60669acf70ee

通用对话子系统是 HippoxOS 的基础交互层，是用户与操作系统交互的统一入口。该子系统基于 Hippox 内核构建，集成了内核的全部调度能力，为所有其他专业领域提供对话基础设施。

当用户输入一段自然语言时，系统首先进行语义分析，判断用户意图是否匹配已注册的驱动程序。如匹配，则从驱动注册表中选取最合适的驱动程序，从自然语言中提取执行所需的参数并进行校验，然后驱动 Hippox 内核调度该驱动执行；如不匹配，则回退到通用 LLM 对话模式。对于复杂任务，系统支持将用户意图分解为多个子任务并编排执行顺序，同时维护多轮对话上下文，支持任务延续和复杂交互。

**Hippox 内核作为该子系统的底层调度引擎**，提供以下核心调度能力：

- **驱动注册与调度**：管理所有系统驱动的注册、发现和生命周期，根据意图解析结果调度相应的驱动执行。
- **工作流编排**：支持四种工作流模式，根据任务复杂度自动选择最优执行策略。
- **任务管理**：管理所有执行任务的状态、进度、令牌消耗和执行历史，支持任务的暂停、恢复和取消。
- **资源控制**：控制系统对文件系统、网络、进程等系统资源的访问权限，确保安全执行。
- **错误恢复与重试**：提供统一的超时保护、自动重试和错误恢复机制，保证系统稳定性。

内核以多种工作流模式应对不同复杂度的任务：

| 工作流模式         | 描述                                | 适用场景                       |
| ------------------ | ----------------------------------- | ------------------------------ |
| **ReAct**          | 推理-行动-观察循环，每步由 LLM 决策 | 开放式任务、动态决策、错误恢复 |
| **Batch**          | 批量并行执行多个独立驱动            | 批量处理、独立操作             |
| **Chain**          | 链式串行执行，驱动间可传递变量      | 线性流水线、数据转换链         |
| **PlanAndExecute** | 一次性规划完整工作流，支持条件判断  | 复杂工作流、确定性任务         |

### 2. 视频编辑子系统

https://github.com/user-attachments/assets/9df94a10-6920-4636-9c7d-029b2bf2a04c

视频编辑子系统将传统的非线性编辑工作流转化为对话驱动的创作体验。用户可通过自然语言描述编辑意图，如剪辑片段、调整时间线、添加文字或图像叠加层等。

该子系统底层搭载了自研的 **NLE（Non-Linear Editing，非线性编辑）引擎**，负责所有视频和音频数据的底层处理。NLE 引擎包含以下核心能力：

- **时间线管理**：维护多轨道时间线数据结构，支持视频、音频、文字、图像等不同媒体类型的轨道叠加与同步。
- **多机位渲染**：支持多轨道视频源的同步播放与实时切换，可同时对多个机位画面进行预览和选择，实现多机位剪辑工作流。
- **媒体解码与编码**：支持多种视频、音频、图像格式的解码与编码，提供统一的媒体数据访问接口。
- **片段裁剪与拼接**：对媒体片段进行精确裁剪（基于时间码）、拼接和排列，支持帧级精度的编辑操作。
- **转场与特效**：提供丰富的视频转场效果（淡入淡出、滑动、擦除、缩放等），支持图像特效（变换、缩放、旋转、模糊等）的实时渲染与合成。
- **运镜控制**：支持关键帧动画系统，可对位置、旋转、缩放、焦距等参数进行动态插值，实现推拉摇移跟等专业运镜效果。
- **线性动画**：支持对叠加层（文字、图像）的位置、透明度、旋转、缩放等属性进行线性关键帧动画编排，实现平滑的入出场动画和动态视觉效果。
- **滤镜系统**：内置丰富的滤镜库（LUT 调色、风格化滤镜、颜色分级等），支持实时预览和参数调节，可应用于单个片段或整个时间线。
- **叠加层管理**：支持文字叠加层和图像叠加层的创建、位置调整、样式设置和渲染合成。
- **实时预览**：提供低延迟的实时预览渲染管线，支持编辑操作的即时视觉反馈。

当用户通过自然语言描述编辑意图时，系统解析指令并映射为 NLE 引擎的具体操作。视频创作不再依赖于复杂的时间轴拖拽和参数调节，用户只需用自然语言描述想要的编辑效果，系统通过 Hippox 内核调度相应的视频编辑驱动，驱动 NLE 引擎完成底层媒体处理。

### 3. 3D 沙盒子系统

https://github.com/user-attachments/assets/e2d083fb-8bc5-4ad2-a766-e5112a7b0bb1

3D 沙盒子系统提供了一个通过对话生成和操作三维场景的环境。用户可以用自然语言描述想要构建的 3D 场景，系统生成相应的代码并在视口中实时渲染。所有历史生成的 3D 场景均可回溯和复用，支持场景快照切换和 GIF 动画导出，将 3D 内容创作从代码编写转变为语言描述。

### 4. 地图与地理信息子系统

https://github.com/user-attachments/assets/c1a5f011-7cba-4968-8c16-67cedc336e4b

地图子系统集成了专业级地理信息可视化能力。用户通过对话在地图上标注位置、绘制路径、创建热力图和聚类分析等。系统解析地理意图并在交互式地球视图上叠加相应的图层和标记，将复杂的地理空间分析转化为直观的对话交互。

### 5. 金融数据分析子系统

https://github.com/user-attachments/assets/ca3ce94c-57de-4bed-b633-933fe8f737f3

金融子系统提供实时金融数据可视化与分析能力。用户可通过对话查询和展示股票、加密货币等金融产品的价格走势与技术图表。系统整合实时行情数据、新闻资讯滚动条和交互式 K 线图，使用户能够以对话方式完成金融数据的探索与分析。

### 6. 代码开发子系统

https://github.com/user-attachments/assets/9cc68f1a-0c97-46c9-96c9-d794fd5e2788

代码开发子系统将 AI 辅助编程深度集成到桌面开发环境中。用户可通过自然语言描述开发需求，系统驱动代码生成和修改。该子系统的核心特性是代码变更的可控性——当 AI 对代码进行修改时，系统会以对比视图呈现修改前后的差异，用户确认后方可应用，确保开发者对代码库的完全掌控。

### 7. 定时任务与自动化子系统

定时任务子系统赋予系统无人值守的自动化执行能力。用户可通过自然语言创建定时任务，系统按固定时间或周期性间隔自动执行。任务可以包含自然语言指令或引用 SKILL 文件，支持多种工作流模式选择，并记录完整的执行历史。执行频率以热力图形式可视化呈现，帮助用户洞察自动化任务的运行模式。

## 交互与布局系统

### 统一的多面板布局

HippoxOS 采用一致的多面板布局架构，每个领域工作区由历史会话面板、对话交互面板和主工作区三栏构成。面板支持折叠与宽度调整，布局偏好自动持久化，确保跨会话的使用连贯性。

### 会话管理

系统对所有领域会话进行统一管理，支持会话的创建、切换、重命名、置顶和删除。历史会话按时间自动归类（今天、昨天、最近 7 天、最近 30 天、更早），并支持批量选择与操作，方便用户高效管理大量会话。

### 跨组件事件通信

系统内置窗口级事件总线，各子系统之间通过事件进行解耦通信。编辑操作、播放控制、面板切换和刷新请求等均通过标准化事件机制传递，确保各模块独立演进的同时保持整体协调性。

## 系统定位

HippoxOS 定位为 **"对话驱动的操作系统"**，在传统操作系统内核之上构建了一层智能交互层。Hippox 内核、各领域引擎和桌面环境三位一体，共同构成完整的操作系统体验：

- **面向创作者**：降低视频、3D、代码等专业领域工具的使用门槛
- **面向分析者**：通过对话完成地理信息、金融数据等复杂分析任务
- **面向自动化需求者**：通过自然语言定义定时任务，实现工作流自动化

HippoxOS 的最终目标是让用户与计算机的交互方式从"学习工具如何操作"转变为"描述想要完成什么"，从而释放更多创造力，减少在工具学习上的投入。
